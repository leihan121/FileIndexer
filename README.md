# FileIndexer

基于 C++17 开发的轻量级命令行文件索引与搜索工具。

FileIndexer 使用 C++ 标准库 `std::filesystem` 扫描指定目录，将文件信息保存在内存中，支持文件搜索、扩展名筛选、文件大小排序以及索引持久化。

本项目主要用于实践现代 C++、面向对象设计、STL 容器、文件操作与 CMake 多文件项目构建。

## 功能特性

- **目录扫描**：扫描指定目录下的普通文件。
- **文件信息管理**：记录文件名、路径和文件大小。
- **文件名搜索**：通过完整文件名精确查找文件。
- **扩展名筛选**：按 `.cpp`、`.txt` 等文件扩展名筛选。
- **文件大小排序**：支持升序与降序排序。
- **索引持久化**：将索引保存至文本文件，并在下次启动时重新加载。
- **异常处理**：处理无效路径、文件读取失败等常见错误。
- **交互式菜单**：通过命令行菜单选择不同操作。

### 主要模块

**FileInfo.h**

定义文件信息结构体，包含文件名、路径和文件大小。

**FileIndexer.h**

声明 `FileIndexer` 类以及扫描、搜索、排序、保存和加载等成员函数。

**FileIndexer.cpp**

实现文件索引管理的核心逻辑。

**main.cpp**

提供交互式菜单，负责用户输入与成员函数调用。

## 编译与运行

### 环境要求

- 支持 C++17 的编译器，例如 GCC、Clang 或 MSVC
- CMake 3.16 或更高版本

### 1. 克隆仓库

```bash
git clone https://github.com/leihan121/FileIndexer.git
cd FileIndexer
```

### 2. 构建项目

```bash
cmake -S . -B build
cmake --build build
```

### 3. 运行程序

Linux：

```bash
./build/file_indexer
```

Windows PowerShell（单配置生成器）：

```powershell
.\build\file_indexer.exe
```

如果使用 Visual Studio 多配置生成器，可运行：

```powershell
.\build\Debug\file_indexer.exe
```

## 设计思路

项目采用面向对象的组织方式。

`FileIndexer` 类封装文件索引数据，并通过成员函数统一管理相关操作。

主要设计包括：

1. 使用 `std::vector<FileInfo>` 管理文件信息。
2. 使用 `std::filesystem` 进行目录遍历。
3. 使用 `std::sort` 和 Lambda 表达式进行排序。
4. 使用 `std::ofstream` 与 `std::ifstream` 完成数据持久化。
5. 使用异常机制处理文件系统操作错误。
6. 通过头文件与源文件分离提高代码可维护性。

## 当前限制

- 目前只扫描指定目录的第一层，不递归扫描子目录。
- 文件名搜索采用完整文件名精确匹配。
- 保存的是文件索引快照，不会自动同步磁盘上的文件变化。
- 文件大小以字节为单位。
- 尚未提供图形用户界面。
